## 2. 기능 목록

> 1. 로또 구매 금액 입력
>    > 1. 1000원 단위 검증
>    > 2. 양수 검증
>    > 3. non-Zero 검증
> 2. 로또 생성
>    > 1. 로또 무작위 생성
>    > 2. 생성된 로또 출력
> 3. 당첨 번호 입력
>    > 1. ',' 기준으로 나눔
>    > 2. 요소 개수가 6개인지 검증
>    > 3. 요소들이 정수인지 검증
>    > 4. 요소들의 범위가 적절한지 검증
>    > 5. 겹치는 번호가 없는지 검증
> 4. 보너스 번호 입력
>    > 1. 숫자인지 검증
>    > 2. 범위가 적절한지 검증
>    > 3. 겹치지 번호가 없는지 검증
> 5. 당첨 번호와 생성한 로또 비교
>    > 1. 생성한 로또들과 비교하여 각각 결과 생성
>    > 2. 생성된 결과를 기록함
> 6. 결과 누적 후 출력(당첨 통계 출력)
>    > 1. 누적된 결과 출력
>    > 2. 수익률 출력

---

### 3. 입력 제약 사항

> 1. 보너스 번호 또한 다른 로또 번호와 겹치지 않는 유일한 수
> 2. 0 입력시 에러 발생

## 4. 단위 테스트

### isPerThousand

> **입력과 출력**
>
> - `1000` / `true`
> - `1800` / `false`
> - `0` / `false`
> - `-1000` / `false`

### isPositive

> **입력과 출력**
>
> - `1000` / `true`
> - `-1800` / `false`
> - `0` / `false`

### isNonZero

> **입력과 출력**
>
> - `1000` / `true`
> - `0` / `false`
